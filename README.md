# Pixling Dino: how to use

User guide page for the dino desk pet. The firmware lives in the public repository https://github.com/thelabzero/pixling_dino_firmware; this repo only hosts the guide.

Files: `index.html` (the page), `guide-anims.js` (frames, generated), `gen_guide_anims.py` (regenerates them from the firmware repo: the design reference plus the Wi-Fi screens, drawn by `export_live_frames.cpp`; run `python3 gen_guide_anims.py <path to firmware repo>`, needs a C++ compiler).
